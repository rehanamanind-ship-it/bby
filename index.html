08 // System Control Hook

i gatekeep arch btw

A smart wrapper for pacman -Syu that guards your Arch Linux system against dangerous updates. It flags critical packages (kernel, systemd, glibc, GRUB, and more) before upgrading, detects locally modified config files in /etc/ that could cause .pacnew conflicts, and requires your explicit confirmation before applying anything. Full control over your rolling-release system — zero surprise breakage.

Pacman Wrapper Critical Package Guard .pacnew Conflict Detection
09 // Monolith Refactoring Unit

monolith_splitter

A CLI utility that splits a large monolithic Python file into smaller, organized modules using a CSV-based section map. Designed for scripts that were intentionally sectioned with marker comments, it reads a SECTION_NAME,START_LINE,END_LINE config, generates predictable output files, restores import lines that were commented out for splitting, and warns about unassigned ranges. Packaged as an installable wheel with a simple terminal workflow — no GUI, no notebooks.

CSV Section Map Monolith Refactoring CLI Splitting Wheel Packaging
